la-ai-insight

The framed LawAdvisor AI output panel — one component for every "LawAdvisor AI recommends / has drafted / flagged…" block in the product. A header carries the brand mark and an attributed headline, the body holds the detail, and an optional footer lets the human rate the output and act on it (amend, disagree, view). It encodes the product's human-in-the-loop rule: the AI assists in the header, the human decides in the footer.

Anatomy

Three regions inside a bordered, rounded panel: a tinted header with the inlined LawAdvisor mark and the attributed headline; a body (default slot, or the description fallback); and an optional tinted footer shown when rateable is set or the actions slot is filled.

la-ai-insight

The framed LawAdvisor AI output panel (the X3 pattern). A brand-marked, attributed header, a body for the detail, and an optional footer where the human rates the output and acts on it. One component for every 'LawAdvisor AI recommends / has drafted / flagged…' block.

Properties

PropertyAttributeTypeDefaultDescription

disagreeable disagreeable boolean false Boolean; show the "Something's wrong" Disagree control.
amendable amendable boolean false Boolean; show the "Edit" Amend control and persist the edit stamp.

editedAt edited-at string '' —

_panel — 'none' | 'disagree' | 'amend' 'none' Inline panel currently open in the footer (Disagree or Amend).
_disagreeReason — string '' Working copy of the disagreement reason.
_amendDraft — string '' Working copy of the amended body text.
_bodyText — string '' Plain-text snapshot of the slotted/described body, for seeding the amend editor.
_bodySeed — string — —

edited-by — — — Who last amended the output (drives the "Edited by …" stamp).

Slots

SlotDescription
(default) Body content (overrides `description`).
actions Footer actions, right-aligned (e.g. a "View source" button).

Events

EventTypeDescription
la-rate-state CustomEvent {rated:boolean} whenever the rated state changes — host gates its primary CTA on this.
la-rate CustomEvent {rating:number} when the user picks a thumbs rating (0/1/2).
la-disagree CustomEvent {reason:string} when the user logs a disagreement.
la-amend CustomEvent {value:string} when the user saves an amended body.

CSS custom properties

No public custom properties. Surfaces, borders, and the rating colour are fixed to design tokens for consistency across every AI surface.

Usage examples

Drafted output (header + body)

<la-ai-insight headline="drafted 22 separation packets from the template, agreed terms and Workday profiles">
  Per group: business-reason document (shared). Per employee: redundancy letter +
  severance package (personalised, ADEA waiver for 40+). Review and approve before sending.
</la-ai-insight>

Recommendation the human can rate and act on

<la-ai-insight rateable headline="recommends California packets go out first…">
  Sending CA first preserves the rolling 90-day count…
  <la-button slot="actions" variant="secondary" size="sm">Amend</la-button>
</la-ai-insight>

Listening for a rating

el.addEventListener('la-rate', (e) => save(e.detail.rating)); // 1–5

Notes

  • Owns the branding. attribution defaults to "LawAdvisor AI" and is rendered semibold before the headline — set headline to just the action phrase ("drafted…", "recommends…", "flagged…"). Pass attribution="" on surfaces that already name the AI.
  • Honest, human-in-the-loop framing. Use verbs that say the AI assisted, never decided — "recommends", "has drafted", "flagged". The footer is where the human rates, amends, or disagrees (per the X3 principle). Keep bodies to 1–2 sentences.
  • Self-contained mark. The LawAdvisor glyph is inlined as SVG (currentColor), so the component has no image dependency and the mark can't 404.
  • Footer auto-hides. It only appears when rateable is set or the actions slot has content — a plain drafted-output panel has no footer.
  • Not the same as la-insight-card. That card is the formal legal-area insight (severity icon, source tag, opens the insight modal). la-ai-insight is the generic AI-output framing for narrative drafts, recommendations, and flags inline in a flow.
