la-list-item

Three-column structural row for lists — icon, content, meta, and a trailing actions slot. Non-interactive by default; flip clickable to turn the row into a native button with hover, focus-visible, and keyboard activation. Clicks inside the actions slot do not bubble to the row — consumers can place per-row action buttons without hijacking the main row click.

Two variants: the default row, a row in a ruled list, and variant="card", a row that stands on its own as an elevated card in a grid of its siblings, for a catalogue the founder looks something up in (see Card).

Anatomy

Articles of Incorporation Corporate
  1. Row shell — flex container with align-items: center, gap --la-space-sm, padding --la-space-sm × --la-space-md. Renders as <button> when clickable, otherwise <div>.
  2. Icon — leading column. slot="icon". Auto-hides when empty. Typography size --la-font-size-lg, colour --la-color-text-muted.
  3. Content — default slot. Flex-grows to fill available width, wraps when needed.
  4. Meta — trailing text. slot="meta". Smaller (--la-font-size-sm), muted, nowrap.
  5. Actions — trailing button row. slot="actions". Click-stopped at the container — children do not bubble their click to the row.
  6. Separator — 1px bottom border in --la-color-border-light. Auto-removed on :last-child.

In a card, Meta fills the line under the title, Quiet adds the Coming Soon badge in place of the caret, and Actions draws nothing: a card is one press. Clickable is implied.

Card

Set variant="card" for a row that stands on its own: an elevated card in a grid of its siblings, for a catalogue the founder looks something up in. It is drawn from Orion's documents and single steps in 05-playbooks.html, in new-design: an area page's Documents and single steps, the library search's results and the Documents catalogue. A card acts, so it is elevated and lifts to --la-shadow-card on hover and focus (rule/one-card-surface), and it is always a native button, with clickable implied. The leading slot takes a glyph on a 32px tile or a picture that fills it; the default slot is the title and the description slot its one line; the card draws a caret unless the meta slot holds something in its place.

la-list-item

Three-column structural row for lists — icon, content, meta, and a trailing actions slot. Non-interactive by default; flip clickable to turn the row into a native button with hover, focus-visible, and keyboard activation. Clicks inside the actions slot do not bubble to the row — consumers can place per-row action buttons without hijacking the main row click. Set variant="card" for a row that stands on its own: an elevated card that always opens, in a grid of its siblings.

Properties

PropertyAttributeTypeDefaultDescription
error error boolean false Tints the row background with `--la-color-surface-danger`.
clickable clickable boolean false When true, the row renders as a native button — tab-focusable, keyboard-activated, hover + focus styles. Implied by the card variant.
variant variant 'row' | 'card' 'row' `row` (default): a row in a ruled list. `card`: a row that stands on its own as an elevated card, always a button, for a grid of siblings such as a catalogue.
quiet quiet boolean false Card only. Steps the card back for something not ready yet (the picture greys, the glyph's tile turns dashed, the title goes secondary); it still opens. Put the badge that says why in the meta slot.

Slots

SlotDescription
icon leading column: a glyph or an avatar; in a card, a glyph on a 32px tile or an image (an img element) that fills it
(default) the row's content; in a card, its title (text), one line, cut short with an ellipsis
description a card's one line under the title, cut short with an ellipsis (card only)
meta trailing text; in a card, a badge in place of the caret it draws when this is empty
actions trailing buttons whose clicks never reach the row (row only: a card is one press)

Usage examples

Basic — content only

<la-list-item> Articles of Incorporation </la-list-item>

Icon + content + meta — typical three-column

<la-list-item> <i slot="icon" class="ph ph-file-text"></i> Articles of Incorporation <span slot="meta">Corporate</span> </la-list-item>

With actions — edit + remove icon buttons

<la-list-item> Alex Chen <span slot="meta">CEO</span> <span slot="actions"> <la-icon-button size="sm" label="Edit"> <i class="ph ph-pencil-simple"></i> </la-icon-button> </span> </la-list-item>

Clickable row — listen for native click

<la-list-item clickable> <i slot="icon" class="ph ph-file-text"></i> Articles of Incorporation </la-list-item> const item = document.querySelector('la-list-item'); item.addEventListener('click', () => { // open detail view, navigate, etc. });

Person row — avatar + name + role + actions

<la-list-item clickable> <div slot="icon" class="avatar">AC</div> Alex Chen <span slot="meta">Founder · CEO</span> <span slot="actions"> <la-icon-button size="sm" label="Edit"> <i class="ph ph-pencil-simple"></i> </la-icon-button> </span> </la-list-item>

Notes

Click-stop on the actions slot — clicks inside the actions slot do not bubble to the row click. This lets you put per-row action buttons (edit, remove, more) without the row click firing whenever a user taps an action. The row click still fires for everything else — the content column, the icon, the meta.
Interactive pattern matches la-document-item — when clickable, the row is a native <button> with a ::before pseudo-element hover fill (--la-color-bg-muted) and a :focus-visible ring. See decisions/16 (native-button rows) and decisions/17 (GPU-safe hover pseudo).
Error background wins over hover fill — when error is set, the danger-surface background stays visible even on hover. The pseudo-element hover fill is suppressed so the error signal is never obscured.
Stacked lists just work — place multiple la-list-items back-to-back and the bottom separator appears between siblings; :last-child auto-removes the final border. No separator primitive needed.
Inset focus ring — the focus ring uses a negative outline-offset to sit inside the row. Rows sit flush against siblings via border-bottom, so an outset outline would overlap adjacent rows. This diverges from la-document-item's outset ring — intentional, driven by the container context.
Composition note — la-list-item covers director-row, person-row, and coverage-row patterns that appear across the founder-flow prototypes. Prefer it over handwritten <div class="row"> chrome.
A card always opens: an elevated surface says it responds (rule/one-card-surface), so variant="card" renders the native button whether or not clickable is set. A list whose rows do nothing stays on the default row.
Quiet is not disabled: a quiet card is for something not ready yet, and it still takes focus and still opens, so the page can say why. In 05-playbooks.html (in new-design) a quiet document opens the modal that says it isn’t available yet and offers Ask an Expert. The badge in the meta slot says the state; the tile and the title step back with it. quiet means what it means on la-tile: it steps back and still acts. There is no disabled card, because no catalogue row today is a door that can’t open.
One press, one name: a card has no actions slot, so it is a single tab stop with a single click. Its accessible name is its content (the title, the line and any badge), so give a glyph aria-hidden="true" and a picture alt="".
The grid is the page's: the card fills its grid cell and stretches to the row's height, and lets the cell shrink below its title (min-width: 0 on the host), so a long title truncates instead of widening the column. Lay cards out two up, --la-space-sm apart, and one up on a phone.
What the card leaves alone: --la-list-item-inset is for a row that runs edge to edge; a card keeps its own padding. The default row draws exactly as it did before the card existed (see the run row above).
Hidden works: hidden on any la-list-item takes it out of the layout, so a page that filters its rows (the Documents catalogue's search) can hide one. Before 2 October 2026 the host's own display kept a hidden row on screen.
