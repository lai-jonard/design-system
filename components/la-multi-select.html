la-multi-select

Pick several values from a known set. Current selections sit as removable chips inside a search field; the remaining options show below as one-tap "+" suggestion pills. Typing filters the suggestions. There is no overlay dropdown — the choices stay in view, which suits short, scannable option sets (jurisdictions, tags, OpCos). Options and selection accept comma-separated strings in HTML or arrays in JS.

Anatomy

A bordered field with a leading search glyph, the selected values as chips, and a flex-grow text input. Below the field, the unselected options render as outlined "+" pills. The field shows the standard focus ring; chips carry a remove button; pills add on click.

la-multi-select

Token multi-select with a searchable field and add-on suggestion pills. Selections sit as removable chips inside the field; the remaining options show below as one-tap '+' pills. Typing filters them. No overlay dropdown.

Events

CSS custom properties

No public custom properties. Field chrome (border, focus ring, radii) and the chip/pill surfaces are fixed to design tokens to match la-input and la-select.

Usage examples

Comma-separated in HTML

<la-multi-select label="Jurisdiction/s"
  options="California,New Jersey,Texas,New York,Florida"
  selected="California,New Jersey,Texas"></la-multi-select>

Arrays + reacting to change

el.options = ['California', 'New Jersey', 'Texas'];
el.addEventListener('la-change', (e) => {
  // e.detail: { selected: string[], action: 'add' | 'remove', value: string }
  save(e.detail.selected);
});

Allow values that aren't in the list

<la-multi-select label="Tags" allow-custom max-suggestions="6"></la-multi-select>

Notes

  • No overlay dropdown. Suggestions render inline below the field, so they never clip and there's no open/close state to manage. Best for short-to-medium option sets; for very long lists, cap with max-suggestions or pair with search.
  • Keyboard. Type to filter; Enter adds the top match (or the typed value when allow-custom); Backspace on an empty input removes the last chip. Each chip's remove button and each suggestion is independently focusable.
  • Data shape. Entries are plain strings (value = label). Pass {value, label} objects via the JS options/selection when they differ; comma-separated attributes are string-only.
  • State, not store. The component owns selected and reflects it to the attribute, firing la-change on every add/remove — the consumer persists.
  • Not la-select. Use la-select for a single value from a dropdown; la-multi-select for several values shown as chips with always-visible suggestions.
