la-welcome-banner

First-time hero on the dashboard. A single calm surface that names what we're about to do, sets the time expectation, and offers one obvious next step. Visible until the user finishes Corp Gov L0 — once L0 is complete the dashboard swaps to the four-widget grid and this surface is gone. Status note: descoped from Sprint 2 (2026-05-05) — the canonical pre-L0 surface is a welcome form, not a banner. This page documents the component as built, for a future sprint that adopts the welcome-first proposal.

Anatomy

One plain white surface, three regions stacked vertically: heading, description, then a single primary call-to-action.

Usage examples

Default — the FTUE entry point

<la-welcome-banner @la-welcome-cta="${startUnlock}"></la-welcome-banner>

Defaults assume Corp Gov L0 as the first task — change the props for any future first-task variation.

Custom copy

<la-welcome-banner heading="Welcome back, Jonard" description="You're three steps from a complete picture." cta-label="Resume governance review" ></la-welcome-banner>

Pair with the dashboard layout (Sprint 2 single-column 1120px max-width)

<main class="dashboard-shell"> <la-welcome-banner @la-welcome-cta="${startUnlock}"></la-welcome-banner> <!-- four locked legal-area widgets follow --> </main>

Hide in place — usually you'd unmount instead

<la-welcome-banner dismissed></la-welcome-banner>

Sprint 2 swaps this surface out of the DOM once Corp Gov L0 succeeds — dismissed covers cases where the element stays mounted.

Notes

Descoped from Sprint 2 (2026-05-05). No canonical home in any current sprint solve — the pre-L0 surface is a welcome form (jurisdiction + company name + Continue), not a banner. Source stays in the tree; this page is the reference if a future sprint adopts the welcome-first proposal. See the component's entry in handoffs/readiness.md.
FTUE only. Visible while Corp Gov L0 is incomplete (backend state check, not visit count). Once L0 succeeds the dashboard re-renders into the four-widget grid and the banner is gone.
Self-contained, not an alert variant. Decision 25 walked back an attempt to absorb welcome into la-alert size="lg". The dashboard greeting carries different rhythm (heading + description + single CTA) than the inline alerting pattern la-alert serves; keeping them separate prevents one component growing two opposing centres of gravity.
One CTA only. The banner shows the next obvious step — adding a secondary action would dilute it. If you need two paths, that's a design conversation, not an extra slot. An empty ctaLabel drops the button entirely for informational use.
British English, sentence case, verb-first. Default copy follows the house copy rules. Custom copy must too.
Composes la-button. The CTA is a real button, not a styled span. Hover, focus-visible, keyboard activation, and disabled state all come for free.
