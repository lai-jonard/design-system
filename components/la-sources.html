la-sources

Where something came from. A ghost Sources · 2 pill opens a panel naming the documents and registers a step, an insight or a deadline read from, so whenever we assert something the founder can see its source in one click. It’s provenance, not the law: a step’s legal grounding stays behind More. With no sources it draws nothing.

Anatomy

  1. Pill. A ghost la-button at the small size: the label, then the count.
  2. Panel. In the top layer, below the pill: a title, then one row per source: its icon (a file for a document, buildings for a register, a table for the cap table), its name, and where in it.
  3. Rows. A row with somewhere to go is a link with the open-out arrow; one without is plain text. On a touch screen each row is at least 44px tall.

Live preview

Open the pill and press a row: it’s a link. This page takes the click over, as a page that opens the source itself would, and logs where it goes. Escape closes the panel and returns focus to the pill. Pick none and the pill goes.

Properties

PropertyAttributeTypeDefaultDescription

Slots

SlotDescription

Methods and events

NameWhat it is
close()Closes the panel, from the page.
clickThe native event. A row with href is a link, so the browser follows it, and the panel closes. A page that opens the source itself listens for click on la-sources and calls preventDefault(); the link is the first a in e.composedPath() (decision 142). No event of its own: la-source-open went on 14 Oct 2026 (SR3).
emptyAn attribute the host takes while it has no sources, and draws nothing. Read it; don’t set it.

A long list scrolls inside the panel from min(70vh, 560px), as la-run-overview’s does (decision 148, RO4). The 1px between rows, the rows’ 1.25 line height and the focus ring’s -2px inset are fixed, as in la-run-overview and la-menu. It fades in over --dur-fast, and at once under reduced motion.

Usage examples

On a step’s foot, through la-playbook-step’s sources slot.

<la-sources slot="sources"></la-sources> el.sources = [ {icon: 'ph-file-text', doc: 'Articles of Association', section: `uploaded ${formatDate('2024-06-02')} · LawVault`, href: '/lawvault/articles'}, {icon: 'ph-buildings', doc: 'Companies House', section: 'the disqualified directors register', href: '/registers/disqualified-directors'} ];

Opening a source in the page instead of following its link (decision 142).

el.addEventListener('click', (e) => { const a = e.composedPath().find((n) => n.localName === 'a'); if (!a || e.metaKey || e.ctrlKey || e.shiftKey) return; e.preventDefault(); openPreview(a.href); });

With a page’s own trigger.

<la-sources> <la-button slot="trigger" variant="ghost" size="sm">Where this came from</la-button> </la-sources>

Notes

  • Where it’s used. la-playbook-step’s foot. Orion’s run, Insights and Deadlines draw their own copy (sources.js) and move onto this once the sync resumes.
  • No sources, nothing drawn (Jonard, 16 Oct 2026). With an empty list there’s no pill, no panel and no page trigger, which would open nothing. The host takes empty and no space, and an open panel closes, so a page can pass whatever it has without counting first. Sources that arrive later draw the pill as usual.
  • On a touch screen each row is at least 44px tall (--la-button-height-lg; responsive-design.md’s touch targets), plain rows too so a list keeps one rhythm, and its icon and arrow centre on the row. The pill is la-button’s small size, which has no touch padding of its own.
  • On a narrow screen the panel is never wider than 90% of the window, and stays inside it: it aligns to the pill’s right edge, or to its left edge when there’s no room to the left, and opens upward when there’s no room below. It stays a popover on a phone, as la-run-overview’s does.
  • A disclosure (decision 143; rule/popover-by-content). The trigger carries aria-expanded and aria-controls, focus stays on it as the panel opens, and Tab moves into the rows. Escape returns focus to the button inside the pill, which la-button doesn’t do for its host, and the pill’s aria-expanded is on that button so a screen reader hears it. Beyond baseline, still open: on a slotted la-button trigger, aria-expanded and aria-controls land on the host, where a screen reader doesn’t hear them, and aria-controls can’t reach a panel inside the shadow root.
  • In the top layer (decision 143, built 14 Oct 2026). The panel is a manual popover, right after the pill in the page, so no box that scrolls can clip it and reading order holds. CSS anchor positioning places it; where the browser lacks it (or its flips), it’s placed from the pill’s position, moved on scroll and resize, and kept inside the window. Manual, not auto, so it keeps the disclosure’s own rules: one open at a time, a click outside or Escape closes it, and Escape is taken before a modal’s, so it closes the panel and not the modal.
  • Decided 14 Oct 2026 (decision 151; built 14 Oct 2026): the pill stays, one click away, reading Sources · N (SR1, A); far right of the foot (SR2, A); a row with a destination is a link (SR3, B); it opens below and flips up when there’s no room (SR4, B); the note slot goes (SR5, B). Gone: the nav field (now href), the la-source-open event, the note slot, and the drop property, whose upward default existed so a pill at a card’s foot didn’t push the page, which the top layer never does.
