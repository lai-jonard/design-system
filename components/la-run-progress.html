la-run-progress

How far a playbook run has got: “2 of 9 steps done”, then a 6px la-progress bar, named for the run. It counts settled steps (done, moved past, or done before you started) over every step in the run, and stays neutral at every value: the steps’ own check markers say which are done. It heads la-run-overview’s popover.

Anatomy

  1. Count. “2 of 9 steps done”, first, in the secondary text colour with tabular numbers: it names what it counts (decision 148). Hidden from screen readers, which hear the bar instead.
  2. Bar. la-progress at lg (6px), neutral, filling the rest of the line. It carries the role, name and value: named for the run, “Appoint a director”, valued “2 of 9 steps done”. The name never changes as the run moves; the value does.

la-run-progress

How far a playbook run has got: “2 of 9 steps done”, then a 6px la-progress bar, named for the run. It counts settled steps (done, moved past, or done before you started) over every step in the run, and stays neutral at every value: the steps’ own check markers say which are done. It heads la-run-overview’s popover.

Properties

PropertyAttributeTypeDefaultDescription
done done number 0 settled steps
total total number 0 every step in the run
label label string 'Playbook progress' the bar's accessible name: the run's title (default "Playbook progress", where there's none)

CSS tokens

TokenUsed for
--la-space-mdThe gap between the count and the bar.
--la-color-text-secondaryThe count.
--la-font-size-mdThe count’s size.
--la-progress-height-lgThe bar’s height, through la-progress.

Usage examples

A run with five of ten steps settled, named for the run.

<la-run-progress done="5" total="10" label="Appoint a director"></la-run-progress>

In la-run-overview, its run-title names the bar.

<la-run-overview run-title="Appoint a director" .sections=${…}></la-run-overview>

Notes

  • What counts. A step counts once it settles: done, moved past with a reason, or done before you started. Jonard closed RP1 on 13 Oct: moved past counts as done, as Jira counts Cancelled (decision 133).
  • The whole run. total is every step: in Phase B no step leaves the run (decision 124).
  • Neutral. The fill never turns green, even at 9 of 9: the steps it sums up are on the same screen, and their check markers say done (decision 132, rule/green-on-a-check).
  • The count reads first, then the bar (Jonard, 12 Oct 2026; Bobby’s CMS 07 draws it in that order).
  • Where it lives. It heads la-run-overview’s popover, while the pill keeps the count on the page. The run page doesn’t also show it under the intro: RP2 closed 14 Oct, A (decision 148).
  • Words. RP3 closed 14 Oct, B (decision 148), built 14 Oct: the visible count names its noun, “2 of 9 steps done”, as the bar’s value does, and the bar is named for the run, its title, with “Playbook progress” only when there’s none. The name stays put as the run moves; the value changes.
  • Not this: a bar for an operation with no steps on screen is la-progress, which can take a variant; the step you’re on is la-step-marker.
