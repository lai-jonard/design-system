la-date-input

A date someone knows, typed: three numeric parts in one field, in the reader’s locale’s order, with the format as its hint. It’s checked only when the page asks, on Next, with check(). It never opens a calendar; a date picker or a date range can compose it later. Its value is an ISO date, and empty while the date is part-typed or impossible. The questions modal uses it for a date question and for changing a date on your record.

Anatomy

  1. Legend. The fieldset’s name: label shown, or aria-label for screen readers only. Required adds an asterisk; optional says so.
  2. Parts. Day, month and year in the reader’s locale’s order (month first in en-US), each a labelled numeric field, with slashes between them. Typing stays in a part until you move.
  3. Hint. The format (“DD/MM/YYYY”), after the page’s own hint when there is one: never only the placeholder (decision 145). A message from check() replaces it, in the same polite live region.

Live preview

Each control sets a property. Type a date: the log shows each la-change. Nothing is checked as you type or leave the field; Next calls check(), as the questions modal does, and a message then clears as soon as the date is put right.

la-date-input

A date someone knows, typed: three numeric parts in one field, in the reader’s locale’s order, with the format as its hint. It’s checked only when the page asks, on Next, with check(). It never opens a calendar; a date picker or a date range can compose it later. Its value is an ISO date, and empty while the date is part-typed or impossible. The questions modal uses it for a date question and for changing a date on your record.

Properties

PropertyAttributeTypeDefaultDescription
value — — — The date as ISO YYYY-MM-DD (the value attribute too). Empty while it's part-typed, impossible or outside min and max.
locale locale — — The reader's browser locale by default, not en-US (decision 145).
label label string '' The visible name, the fieldset's legend. Without it the legend is hidden and reads aria-label, or "Date".
hint hint string '' The page's own guidance, shown before the format: "The date in the board minutes · DD/MM/YYYY".
min min string '' The earliest date allowed, ISO. Earlier fails check() with "Enter a date on or after …".
max max string '' The latest date allowed, ISO. Later fails check() with "Enter a date on or before …".
ariaLabel aria-label string '' The name when the question above already shows it, as la-question sets it.
required required boolean false Empty fails check() with "Enter the date."; the legend shows an asterisk.
optional optional boolean false Shows "Optional" after the legend, as la-input does.
disabled disabled boolean false Disables all three parts.
error error boolean false The error look. check() sets it; one the page sets stays until the page clears it.

Events

EventTypeDescription
la-change CustomEvent —

Methods

check() checks the date now, as the page asks on Next: it shows the message, sets error, and returns true when the date is whole, real and inside min/max, or empty and not required. focus() moves to the first part.

Usage examples

A labelled date in UK order.

<la-date-input label="Date of appointment" locale="en-GB"></la-date-input>

A question’s answer, named by the question, kept only once the date is whole.

<la-date-input .value=${answer} aria-label=${question} @la-change=${(e) => set(e.detail.complete ? e.detail.value : '')}></la-date-input>

Notes

  • No calendar. It’s for a date someone knows; a picker or a range composes it later.
  • Editing a finished date keeps the other parts (12 Oct 2026 fix): a value the field already holds is ignored.
  • Decided 14 Oct 2026 (decision 149; built 14 Oct 2026): three parts in one box (DI1); the reader’s locale, from the browser (DI2, decision 145); checked when the page asks, on Next, with check(), never as it’s left (DI3, decision 156); no moving on by itself as you type (DI4); messages that say what’s wrong, never “valid” (DI5). A message clears as soon as the date is put right (decision 156). Its width is decision 146 (X9) and the date’s display format decision 145 (X8).
  • The message’s look is the forms foundation’s error (decision 140, amended 15 Oct 2026; built in design#100): --la-font-size-md, --la-color-urgent-text, led by ph-fill ph-warning-circle, under the field in the hint’s place. The box keeps its red border.
  • Readiness: excluded from document generation on 6 Aug 2026; the questions modal has used it since 6 Oct.
