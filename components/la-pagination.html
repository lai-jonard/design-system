la-pagination

"Showing 1–20 of 45", previous, first / neighbours / last with ellipses, next. The host owns the data and slices it on la-page-change; the component only says which page is current. When everything fits on one page it renders nothing.

Anatomy

Range on the left, pager on the right. The current page is the inverted pill; disabled arrows go faint rather than disappearing so the row never shifts.

la-pagination

The range line and numbered pager under a list — Option 1 of the pagination study, made once. Hides itself when the list fits on one page.

Properties

PropertyAttributeTypeDefaultDescription
total total number 0 items in the list after narrowing
pageSize page-size number 20 items per page (attribute `page-size`), default 20
page page number 1 current page, 1-based; the host sets it back after la-page-change
noun noun string '' optional word after the range ("Showing 1–20 of 45 documents")
single single boolean true —
pages — number — —

Events

EventTypeDescription
la-page-change CustomEvent {page, from, to} (from/to 0-based, half-open, for slicing)

Usage

  • Set total to the count after narrowing, and reset page to 1 whenever the narrowing changes — page 3 only means something relative to one particular list.
  • On la-page-change, slice with detail.from / detail.to (0-based, half-open) and scroll the list top into view.
  • Default page size is 20 (LawVault). The Dashboard feed uses 8, hidden below nine items — pass page-size="8"; the hide rule falls out of it.

Notes

Three hand-rolled copies existed on Dashboard, Company Manual and LawVault (.feed-pager). Study: dev/prototypes/pharos/_pagination-options.html, decided 1 Sep 2026. Decision 99.
