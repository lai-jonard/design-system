la-chip

A removable token for a narrowing in force. It answers "why am I seeing one row?" on a status line: one chip per filter, scope or pick, and each × drops that narrowing alone. Fires la-remove.

Anatomy

Optional quiet prefix, the label, and the × glyph. The whole pill is one button — there is no separate close target to miss.

  1. Prefix — what kind of narrowing ("Area", "Status"). Muted, optional.
  2. Label — the value in the founder's words.
  3. Remove — 9px × glyph; the button is the whole chip.

la-chip

A removable token for a narrowing in force — an active filter, a scope, a picked person. The whole chip is the remove control. Kept apart from la-badge because a badge is inert and a chip is pressable.

Properties

PropertyAttributeTypeDefaultDescription
label label string '' what the narrowing is ("Employment")
prefixText prefix string '' Attribute stays `prefix`; the property is `prefixText` because `Element.prefix` already exists.
value value string '' machine value carried in the event
removable removable boolean true default true; false renders a read-only token with no ×
prefix — — — optional quiet lead-in ("Area", "Status"); reads "Area: Employment" (property: prefixText)

Events

EventTypeDescription
la-remove CustomEvent {value, label}

Usage

  • One chip per narrowing in force; never a chip for the default state ("All Areas" is not a chip).
  • With one chip its × already is Clear all — show a Clear all control only from two chips.
  • Wrap chips in an element with role="list" and aria-label="Active filters"; the chip's own label reads "Remove filter: Area: Employment".
  • Not a status: a document's state is a la-badge appearance="ghost". Not a document: a staged file is a la-chat-attachment-chip.

Notes

Replaces the hand-rolled .ix-scope-chip in the Pharos options bar (15 Sep 2026). Rules: rule/ghost-status-badges (anything that looks pressable must be pressable), rule/state-said-once. Decision 99.
